# Airyolk HSE Dashboard

A single-page, print-ready Health, Safety, and Environment (HSE) KPI dashboard for Airyolk NIG Ltd.

This project is built as a standalone HTML dashboard that presents key HSE metrics, comparisons, trends, and executive summary graphics in a polished, report-ready layout.

## Overview

- File: `Airyolk_HSE_Dashboard_A4.html`
- Format: HTML with inline CSS
- Purpose: Display HSE performance metrics, year-on-year comparisons, target status, and high-level insights in a visually engaging layout.
- Layout: Designed for A4-style presentation and easy viewing in a browser.

## Key Sections

- Executive summary with top KPI highlights
- Year-on-year KPI comparison tables
- Cumulative YTD performance data
- Trend bars and target insight visuals
- HSE contact details and focus areas
- Print-ready styling for easy sharing

## How to Use

1. Open `Airyolk_HSE_Dashboard_A4.html` in a web browser.
2. Review the HSE metrics and status indicators.
3. Use the browser print dialog to export as PDF if needed.

## Customization

- Update dashboard values directly in the HTML table rows and stat blocks.
- Modify the CSS style block for color, spacing, typography, or layout changes.
- Add more KPI rows or cards by copying existing table rows and adjusting the content.

## Notes

- No external dependencies are required other than the Google Fonts import used for typography.
- The dashboard is optimized for a single-page printed report style.
- This file is ideal for executive summaries, safety meetings, and management reviews.
